# Retain the workspace blueprint assembler

Keep `init-workspace` as a supported assembler for an authored blueprint, exact
static catalog, and explicit values, while full `render` owns the standard
stack planner. This retains the useful CSE trial interface and its safe-output
and provenance controls without creating a competing package-selection
language. Existing trial layout, lockfiles, and per-compiler Foundation policy
remain unchanged; production full-render work and broader reuse are separate.
